# Running example

A copy of the running example log of the location-based OCPM project (`data/running_example/running_example.sqlite` there, generated by its `make_running_example.py`).
17 events, object types slab (s1) and coil (c1 to c5); example time t is 2026-01-01 00:00 plus t hours.
This module uses only the log itself (events, objects, e2o), none of the configuration inputs of the location module.
